# Agents Guidelines

This document outlines the responsibilities and guidelines for agents working on this front-end website project.

## Project Assets

- **Homepage Design Image**: `homepage-design.png`  
  Reference the visual layout, components, and styling from this image when implementing the homepage.

- **Design Documentation**: `design.md`  
  Contains detailed design specifications, typography, color schemes, and component guidelines. Always consult this file before making changes to the UI.

## Agent Responsibilities

1. **Code Implementation**
   - Convert design specifications from `design.md` and `homepage-design.png` into clean, maintainable code.
   - Use semantic HTML and ensure accessibility (WCAG 2.1 standards).
   - Organize CSS/SCSS or styling in a modular, reusable way.
   - JavaScript/TypeScript code should follow ES6+ standards.

2. **Code Quality**
   - Follow consistent code style and formatting (use Prettier or ESLint where applicable).
   - Comment complex logic for readability.
   - Keep functions small and focused; avoid large monolithic blocks.
   - Write reusable components whenever possible.

3. **Testing & Validation**
   - Test UI elements across modern browsers and devices.
   - Ensure forms, buttons, and interactive elements work correctly.
   - Validate HTML/CSS for errors and warnings.

4. **Collaboration**
   - Commit code regularly with clear, descriptive messages.
   - Use branches for feature development and submit pull requests for review.
   - Document changes and reasoning when deviating from the original design.

5. **Assets & Resources**
   - Keep images, icons, and other assets organized in appropriate folders (e.g., `/assets/images`).
   - Optimize images for web performance without losing quality.

6. **Performance & Best Practices**
   - Minimize unnecessary DOM manipulations.
   - Lazy-load images and other resources when possible.
   - Optimize CSS and JavaScript for fast load times.

## Notes

- Always refer to `design.md` for exact color codes, spacing, and component behavior.
- Use `homepage-design.png` to check layout accuracy.
- Follow accessibility and responsive design best practices to ensure a quality user experience.
- Use the `work.md` file to create notes on what work is complete.
